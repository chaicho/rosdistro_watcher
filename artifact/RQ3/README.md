# RQ3: Automation Barriers

Analyzes naming inconsistencies among packages grouped under the same key.

## Files

### Scripts
- `RQ3.py` - Main analysis script
- `filelist_similarity_analysis.py` - Rebuilds the package-file-list
  similarity intermediate used by the structural/content analysis

### Usage
```bash
# From the repository root, in the artifact container:
python artifact/RQ3/scripts/RQ3.py

# Rebuild of no_overlap_pairs.csv:
python artifact/RQ3/scripts/filelist_similarity_analysis.py
```

The main RQ3 command uses `artifact/RQ3/data/no_overlap_pairs.csv`, so in the
artifact Docker environment it runs quickly with the packaged cached data. The
optional `filelist_similarity_analysis.py` command refreshes package-repository
metadata, can take much longer, and may produce different intermediate files
because external repositories evolve over time.
Use a disposable container when regenerating reference data.

`RQ3.py` loads the frozen `rosdep/` snapshot, identifies cross-platform entries
with exactly one package per repository entry, and measures whether the package
names differ after minimal repository-specific normalization. It writes the
following files under `artifact/RQ3/data/`:

- `rq3_summary.txt`: top-level counts for entries analyzed, naming-inconsistent
  entries, and root-cause categories.
- `all_inconsistent_entries.txt`: every naming-inconsistent rosdep key and its
  category labels.
- `affixation_entries.txt`, `evolution_entries.txt`, and
  `policy_entries.txt`: per-category inspection lists.
- `overlap_summary.txt`: overlap between naming-inconsistent entries and the
  packaged file-list no-overlap intermediate.

Expected output from the packaged data is 1,737 entries analyzed, 1,331
naming-inconsistent entries (76.6%), with category counts affixation=1,007,
evolution=240, policy=526, and unknown=0. The structural/content overlap count
reported in the paper is 568 entries, read from `overlap_summary.txt`.

`filelist_similarity_analysis.py` rebuilds only
`artifact/RQ3/data/no_overlap_pairs.csv`. Each row is a pair of repository
packages for the same rosdep key whose installed file lists have Jaccard
similarity 0.0. `RQ3.py` then summarizes how many of those zero-overlap entries
also appear in the naming-inconsistent set.


### Data
- `all_inconsistent_entries.txt` - The full list of dependency entries identified as naming-inconsistent across repositories
- `affixation_entries.txt` - The subset attributed to divergent affixation rules (e.g., `libstdc++` vs `stdc++`)
- `evolution_entries.txt` - The subset attributed to repository evolution
- `policy_entries.txt` - The subset attributed to differing packaging policies
- `no_overlap_pairs.csv` - Packaged file-list similarity intermediate used to compute the structural/content-overlap count reported in the paper
- `rq3_summary.txt` - The main naming-inconsistency summary generated by `RQ3.py`
- `overlap_summary.txt` - The packaged structural/content-overlap summary generated from `no_overlap_pairs.csv`
