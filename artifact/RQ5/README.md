# RQ5: Defect Diagnosis Effectiveness

Evaluates RosdepAuditor's ability to diagnose defects using 83 manually verified ground truth defects.

## Files

### Scripts
- `run_experiments.py` - Builds ground truth database and runs defect diagnosis evaluation
- `build_rq5_database.py` - Builds the frozen PR candidate database skeleton for manual RQ5 annotation

### Usage

#### Reproduce paper-facing result
```bash
python artifact/RQ5/scripts/run_experiments.py analyze
```

This is sufficient to regenerate `defect_detection_recall.md` from the
packaged candidate dataset and manually completed verification file.

#### End-to-end workflow

1. Build the PR candidate skeleton:
```bash
python artifact/RQ5/scripts/build_rq5_database.py
```

This writes `artifact/RQ5/data/rq5_database.csv` with PR metadata and
automatically extracted `modified_keys`. The candidate set contains PRs from
the May-September 2025 window plus historical B.2 PRs from the RQ1 manual
dataset. The `classification_types` column is intentionally left blank for
manual ground-truth annotation.

2. Fill ground-truth classifications:

Manually fill `classification_types` in `artifact/RQ5/data/rq5_database.csv`
for the PRs selected for RQ5 analysis. This column is the human-labeled defect
type set, such as `A.1`, `A.2`, `B.1`. It is not generated
by the build script.

3. Run RosdepAuditor on the manually classified PRs:
```bash
python artifact/RQ5/scripts/run_experiments.py run
```

This reads `classification_types` from `rq5_database.csv`, writes that value as
`expected_types` in `artifact/RQ5/data/rosdepauditor_new_type_analysis_results.csv`,
and adds RosdepAuditor's automated `actual_types`.

4. Verify RosdepAuditor outputs:

Review the generated analysis results and save the checked version as
`artifact/RQ5/data/rosdepauditor_new_type_analysis_results_manual.csv`. This
manual file keeps the generated `expected_types` and `actual_types`, then adds
the verification fields `verified_types` and `verified_reasons`.

5. Generate the recall/precision table:
```bash
python artifact/RQ5/scripts/run_experiments.py analyze
```

This reads the candidate skeleton plus the manually completed results file and
writes `artifact/RQ5/data/defect_detection_recall.md`.

#### run_experiments.py
```bash
cd artifact/RQ5/scripts

# Run RosdepAuditor after manually filling classification_types
python run_experiments.py run

# Generate recall/precision analysis table
python run_experiments.py analyze
```

#### build_rq5_database.py
```bash
python artifact/RQ5/scripts/build_rq5_database.py
```

This rebuilds the frozen candidate skeleton from the May-September 2025 PR
window plus historical B.2 PRs from the RQ1 manual dataset. The separate manual
results file contains the subset that has been analyzed for recall/precision.

### Data
- `rq5_database.csv` - The frozen PR candidate skeleton with automatically collected PR metadata, modified keys, and manually filled `classification_types`
- `rosdepauditor_new_type_analysis_results.csv` - Generated by `run_experiments.py run`; copies `classification_types` into `expected_types` and adds RosdepAuditor's `actual_types`
- `rosdepauditor_new_type_analysis_results_manual.csv` - Manual verification of RosdepAuditor's reported defect types for those PRs, used to compute recall and precision
- `defect_detection_recall.md` - The packaged summary report generated by `run_experiments.py analyze`, containing the paper-facing totals and per-type counts
